# Blogicum (Я-Блогикум)

Социальная сеть для публикации личных дневников. Учебный проект, выполненный
в рамках курса «Python-разработчик» Яндекс Практикума и используемый как
портфолио-проект.

## О проекте

Главный объект блога — **публикация (пост)**, вокруг неё строится вся логика
проекта. У каждой публикации есть заголовок, текст, дата публикации, автор,
локация и категория.

**Логика работы проекта:**

- Без указания категории новый пост добавить нельзя.
- Локация для поста необязательна; если она не указана — отображается
  значение «Планета Земля».
- Автор поста или суперпользователь может установить любую дату публикации,
  в том числе отложенную (в будущем).
- Администратор может снять с публикации любой пост, категорию и локацию.

**Пост отображается на страницах проекта, если одновременно:**

- дата публикации — не позже текущего времени;
- флаг `is_published` равен `True`;
- категория, к которой принадлежит пост, не снята с публикации.

> Локация, снятая с публикации, **не влияет** на отображение связанных с ней постов.

## Функциональность

- Регистрация и аутентификация пользователей
- Создание, редактирование и удаление публикаций
- Загрузка изображений к постам
- Комментарии к публикациям
- Категории (тем) и локации (геометки)
- Профиль пользователя и подписки на авторов
- Пагинация ленты
- Разграничение прав доступа (редактировать пост может только автор)
- Отложенные публикации (дата в будущем)
- Снятие с публикации постов, категорий и локаций
- Кастомная админ-панель с русской локализацией
- Покрытие тестами

## Модели

**Post (Публикация)**

| Поле | Тип | Описание |
|---|---|---|
| `title` | CharField(256) | Заголовок |
| `text` | TextField | Текст публикации |
| `pub_date` | DateTimeField | Дата и время публикации |
| `author` | FK → User | Автор (CASCADE) |
| `location` | FK → Location | Локация (SET_NULL, необязательно) |
| `category` | FK → Category | Категория (SET_NULL) |
| `is_published` | BooleanField | Опубликовано (default=True) |
| `created_at` | DateTimeField | Добавлено автоматически |

**Category (Категория)**

| Поле | Тип | Описание |
|---|---|---|
| `title` | CharField(256) | Название категории |
| `description` | TextField | Описание |
| `slug` | SlugField | Уникальный идентификатор |
| `is_published` | BooleanField | Опубликовано (default=True) |
| `created_at` | DateTimeField | Добавлено автоматически |

**Location (Локация)**

| Поле | Тип | Описание |
|---|---|---|
| `name` | CharField(256) | Название места |
| `is_published` | BooleanField | Опубликовано (default=True) |
| `created_at` | DateTimeField | Добавлено автоматически |

## Установка и запуск

### 1. Клонировать репозиторий

```bash
git clone https://github.com/GoloveshkinaMaria-Dev/ya_blogicum.git
cd ya_blogicum
```

### 2. Создать и активировать виртуальное окружение

**Windows (PowerShell):**
```powershell
python -m venv venv
venv\Scripts\Activate.ps1
```

**Linux / macOS:**
```bash
python3 -m venv venv
source venv/bin/activate
```

### 3. Установить зависимости

```bash
pip install -r requirements.txt
```

### 4. Применить миграции

```bash
cd blogicum
python manage.py migrate
```

### 5. Загрузить фикстуры (тестовые данные)

```bash
python manage.py loaddata ../db.json
```

### 6. Создать суперпользователя

```bash
python manage.py createsuperuser
```

### 7. Запустить сервер

```bash
python manage.py runserver
```

Проект будет доступен по адресу: http://127.0.0.1:8000/
Админ-панель: http://127.0.0.1:8000/admin/
